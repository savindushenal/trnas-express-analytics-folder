# Trans Express Analytics Dashboard

## Project Description

The Trans Express Analytics Dashboard is a web-based analytics application developed to analyse customer complaint and inquiry data. The system provides automated data processing, analytical summaries, interactive visualisations and filtering capabilities to support customer service and operational decision-making.

## Technologies Used

### Frontend
- React
- JavaScript
- Vite
- Recharts
- Axios

### Backend
- Python
- FastAPI
- Pandas
- OpenPyXL
- Uvicorn

## Project Structure

- `backend` - FastAPI backend and data analysis logic
- `frontend` - React frontend and dashboard interface
- `data` - Sample dataset
- `README.md` - Application setup and usage instructions

## System Requirements

- Python 3.x
- Node.js
- npm
- A modern web browser
